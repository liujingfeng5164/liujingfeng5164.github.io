这里是一个安静的角落。

写一点设计，写一点代码，写一些不值得发在别处、但又不甘心忘掉的日常。

## 关于这个站点

- 静态生成：[Hugo](https://gohugo.io/) + [Tailwind CSS v4](https://tailwindcss.com/)
- 后台写作：[Sveltia CMS](https://github.com/sveltia/sveltia-cms)（GitHub PAT 登录，无 OAuth 代理）
- 托管部署：GitHub Pages + GitHub Actions

没有数据库，没有服务器进程，也没有会半夜挂掉的中间层。文字存在 Git 仓库里，和代码一样可以被查看、被回滚。
